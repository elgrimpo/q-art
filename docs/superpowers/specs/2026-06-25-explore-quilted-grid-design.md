# Explore Page: Quilted Grid + Non-Owner Modal Logic

**Date:** 2026-06-25  
**Status:** Approved

---

## Scope

Two loosely related changes to the Explore page and the image-detail modal:

1. Replace the uniform Grid layout with a quilted image gallery
2. Gate iterate/variation actions by ownership — non-owners get a "Make it your own" flow

---

## 1. Quilted Grid

### Layout

Replace the current `Grid + ImageCard` in `src/app/(main_pages)/explore/page.js` with MUI `<ImageList variant="quilted">`. The `ImagesCard` component stays untouched; mycodes is unaffected.

- **Columns:** `cols={4}` on md+, `cols={2}` on xs/sm (via `useMediaQuery`)
- **Row height:** `rowHeight={200}` on md+, `rowHeight={160}` on xs/sm
- **Size pattern:** a repeating 8-item array cycles through the image list:

  | Slot | cols | rows |
  |------|------|------|
  | 0    | 2    | 2    |
  | 1    | 1    | 1    |
  | 2    | 1    | 1    |
  | 3    | 1    | 2    |
  | 4    | 1    | 1    |
  | 5    | 2    | 1    |
  | 6    | 1    | 1    |
  | 7    | 1    | 1    |

  On 2-column mobile, each item's `cols` is clamped to `Math.min(patternCols, 2)` — a `cols:2` pattern item spans the full width, a `cols:1` item is half-width, preserving the quilted rhythm on small screens.

### Item design

Each `ImageListItem` contains:
- Image fills the cell (`width: 100%, height: 100%, objectFit: cover`)
- **No right-click** (`onContextMenu={e => e.preventDefault()}`)
- **Like button** — top-right corner, absolute-positioned (existing `LikeButton` component)
- **Bottom gradient overlay** — `linear-gradient(to top, rgba(0,0,0,0.82) 0%, transparent 60%)`
- Inside overlay:
  - Style chip (same design as sidebar: uppercase, `bgcolor: #2a2a2a`, `color: primary.light`)
  - Prompt text: 2-line max, `overflow: hidden`, `display: -webkit-box`, `-webkit-line-clamp: 2`, `fontSize: 13px`, `color: #e0e0e0`

No URL. No scannability widget. Clicking anywhere on the item opens the existing `ImageModal`.

### Skeleton loading

For the loading state, render 8 skeleton items using the same pattern (MUI `Skeleton` with `variant="rectangular"`, height computed from `rowHeight * rows`).

## 2. Non-Owner Modal Logic

### Context

When a user browses Explore they see images generated by other users. The existing `showUnlockCard = justGenerated || isOwner` already hides the download/unlock card for non-owners. Two gaps remain:

- "New Variation" and "Iterate this image" buttons appear even for non-owners
- The iterate form pre-fills the original owner's URL, which is meaningless for a non-owner generating their own image

### Changes to `IteratePanel.js`

Add `isOwner` prop (default `true` to preserve current behaviour for mycodes/standalone page).

**Default panel (not yet open, not generating):**

| | `isOwner = true` | `isOwner = false` |
|---|---|---|
| "New Variation" block | shown | hidden |
| Second button label | "Iterate this image" | "Make it your own" |
| Second button subtitle | "Edit prompt, style, or QR weight and generate a new version." | "Enter a URL and customise the prompt and style to generate your version." |

**Form state (open, not generating):**

| | `isOwner = true` | `isOwner = false` |
|---|---|---|
| Form title | "Iterate this image" | "Make it your own" |
| URL field | disabled, pre-filled with `image.content` | **editable, starts empty** |
| Prompt field | pre-filled with `image.prompt` | pre-filled with `image.prompt` (inspiration) |
| `isFormValid` | `prompt.trim().length > 0` | `prompt.trim().length > 0 && url.trim().length > 0` |

`initFormValues` reads `isOwner` to decide the initial `url` value: `image.content` if owner, `""` if not.

### Changes to `ImageSidebar.js`

`isOwner` is already derived (`user?._id === image?.user_id`). Pass it to `<IteratePanel isOwner={isOwner} />`.
